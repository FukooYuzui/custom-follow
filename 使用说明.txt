定制关注 · B站与YouTube

开始使用
1. 双击本文件夹里的“启动.cmd”，或 CustomFollow 文件夹内的 CustomFollow.exe。
2. 点击“扫码登录”，用你自己的 B站手机 App 扫码并确认。
   B站可能限制未登录查询，建议先登录。程序不会读取浏览器里的账号或密码。
3. 在“关注管理”输入昵称并选择正确的账号，或直接添加 UID / 空间主页链接。
   例如 https://space.bilibili.com/123456，UID 是主页地址里的那串数字。
   昵称可能重名，请核对头像以外的名称、简介和 UID；暂不支持 b23.tv 短链接。
4. 等待首次检查成功，近期视频会出现在清单中。点击视频打开程序内的“官方网页专注播放”窗口。
5. 关闭主窗口会停止播放、关闭播放器，并收进右下角托盘继续检查。双击粉色电视图标可打开。
   托盘图标可能收在任务栏的向上箭头里。完全退出请使用托盘菜单或程序设置。
   托盘不可用时，关闭主窗口会直接退出。1.1.2 已修复关闭卡死，退出时无需等待网络查询完成。

观看方式
清单中只有你手动添加的 博主，没有全站推荐列表、热榜和信息流。
默认使用 B站官方视频网页，在程序的独立播放窗口中隐藏推荐栏、评论等内容。
顶部“弹幕：隐藏/显示”只控制专注窗口的视觉显示，默认隐藏，不改变 B站账号的弹幕偏好。
播放器仍由 B站提供，保留正常的清晰度、倍速、全屏和登录功能。
已扫码的登录会通过本机浏览器组件尝试同步给 B站，不会把登录凭据写入网页脚本。
请在播放器右下角的清晰度菜单中选择平台提供的画质。
1080P、4K、高帧率等是否可选，取决于视频来源、账号/大会员权限和平台策略；程序不会解锁限制。
若仍显示未登录，请在官方播放窗口自行完成登录。
播放窗口的菜单可以返回关注列表、刷新、切换专注/完整页面或关闭播放。
1.2.0 增加“自动连播我的关注”，默认开启。打开一条视频后，官方专注窗口会按当前清单顺序继续播放，只选择程序中已添加博主的作品。筛选了博主或平台时，只连播打开视频时的筛选结果；最后一条播完停止，不播放站内推荐。
播放页和独立视频窗口顶部可开关连播；B站分 P 会先播完同一作品。返回列表或关闭播放窗口会停止当前连播，取消关注的博主不会被后续选中。嵌入备用模式仍为手动播放。
1.1.4 增加真正全屏：点击顶部“全屏”或按 F11，隐藏窗口标题栏、菜单、顶部工具栏与任务栏。按 Esc 或再次按 F11 退出，恢复之前的窗口状态。B站和 YouTube 都支持。
1.1.3 修复了视频默认缩到右下角的问题。专注模式下视频按比例占用主播放区，竖屏视频居中显示，两侧黑边属于正常比例；不会拉伸画面。
专注样式依赖 B站页面结构；如果官网改版导致控件不可见，可切换完整页面。
清单页也保留“简洁嵌入播放”作为备用，外链播放器的清晰度可能较低。
播放失败可主动点击“在 B站打开”，这会离开专注界面进入默认浏览器。
官方播放器内部登录、会员提示与权限由平台提供；不能保证其未来所有内部推荐都被隐藏。
多分P视频可在播放页切换分P编号。上一条/下一条仅遍历你清单中的视频。

内容同步与可选通知
默认每 5 分钟检查一次，只提醒 博主自己发布的新视频；不提醒图文、转发或直播。
这是定时检查，不是 B站官方实时推送，可能有检查间隔及平台带来的延迟。
第一次检查只建立记录并展示近期视频，不把旧视频当成新更新弹窗。
新视频弹窗可直接打开程序；即使弹窗消失或开启免打扰，视频仍保留在清单中。
可设置提醒声音、免打扰时段（支持跨午夜）、3～60 分钟检查间隔。
免打扰起止相同代表全天免打扰。暂停检查不会在后台拉取新内容。
查询失败会显示具体错误，并延长到 5、10、20、40、60 分钟后重试。
“立即检查”至少间隔 60 秒，且尊重失败退避；重新扫码成功后可立即重试。
初次只拉近期一页，后续最多补查 5 页，本地列表保留最近 500 条。
长时间离线、发布后很快删除的视频，或超出补查范围的历史内容，可能遗漏。
电脑关机、睡眠或完全退出程序时不会检查；需要持续提醒可自行启用开机启动。

登录与数据
账号登录凭据使用 Windows DPAPI 加密，保存在 CustomFollow/data/session.bin。
订阅、设置、播放标记保存在 CustomFollow/data/state.json。
应用日志在 CustomFollow/data/app.log；日志不包含二维码密钥或 Cookie。
WebView 的播放器站点数据在 CustomFollow/data/webview；不要分享整个 data 文件夹。
退出程序内的登录会清空监测凭据及同步的播放器登录，不修改外部浏览器/B站 App 的账号。
本软件没有自己的服务器。视频、图片及账号请求直接发往 B站；设置留在本机。
默认未启用开机启动。如启用后要移动或删除程序，请先在设置中关闭开机启动。

运行与修改
成品面向 Windows 10/11，需要 Microsoft Edge WebView2 运行时（本机已验证可启动）。
若另一台电脑缺少运行时，可从 Microsoft 官方页面安装：
https://developer.microsoft.com/microsoft-edge/webview2/
保留 CustomFollow 文件夹整体，不能单独移动其中的 exe。
main.py、native_ui.py、focus_player.py、bili_api.py、youtube_api.py、state.py、windows_support.py 和 assets 是可编辑源码。
修改后可用 Python 3.12 运行 main.py；build.ps1 会测试并重新生成成品。
自动测试是离线协议/状态/Windows集成验证，不代表 B站未来接口始终可用。
B站接口与策略可能变化；遇到平台验证请在官方渠道处理，程序不会绕过限制。


YouTube 频道
在“关注管理”选择 YouTube，粘贴频道主页链接、@账号或 UC 开头的频道 ID，然后点击添加频道。
例如 https://www.youtube.com/@3blue1brown（示例不会自动添加）。
公开更新检查不需要 Google 登录；不会自动导入 Google 账号里的订阅列表。
优先使用官方更新源，源不可用时读取该频道的公开视频页，最多近期30条。
网页相对发布时间会按近似值显示，更新以视频编号和最新顺序识别。
1.1.5 支持 YouTube 新版“10d ago”等时间缩写，并优先补充官方发布时间。卡片显示发布年月日，鼠标悬停可看具体时间；近似日期标注“约”，未知时间不会用检查时间代替。
YouTube 底部控制栏会跟随窗口尺寸调整，画质菜单超出可用高度时可滚动，保留画质、字幕和全屏等官方选项。
网页备用方式暂不检查独立的 Shorts、直播分栏。
本机网络必须能访问 YouTube，程序不修改网络或代理。
Google 可能限制嵌入式浏览器登录；如无法在播放窗口登录，请用默认浏览器观看。
画质、字幕、广告、账号与地区权限由 YouTube 决定。

从旧版升级
若同一目录中存在 BiliFocus/data/state.json，新版继续使用该数据文件夹；登录、关注和记录均保留。
请先完全退出旧版，再双击启动.cmd 打开“定制关注”。不要删除旧版的数据文件夹。
